Вспомним, что косинусное расстояние - это косинус угла между векторами. 
В нашем случае, вектора - это вектора оценок пользователей у каждого фильма:
```
фильм1 = [оценка_юзера1, оценка_юзера2 ... оценка_юзераN]
фильм2 = [оценка_юзера1, оценка_юзера2 ... оценка_юзераN]
```

```python
m2u_with_norm = r_data.map(lambda x: (x[1], (x[0], x[2]))).groupByKey().mapValues(lambda x: (
    dict(x),
    sum(r[1]**2 for r in x)**0.5
))
```

В `m2u_with_norm` я сделал что-то типо crosstable. Каждому фильму соответствует словарь юзеров и их оценок, а также норма всех оценок у этого фильма

```python
goal = 589
goal2u, goal_norm = m2u_with_norm.filter(lambda x: x[0] == goal).first()[1]
other_movies = m2u_with_norm.filter(lambda x: x[0] != goal)
```

Выделил из всей выборки целевой фильм (589)

```python
cos = other_movies.map(lambda x: (x[0], 
    sum(goal2u[u] * r for u, r in x[1][0].items() if u in goal2u) / (goal_norm * x[1][1])
 ))
```

Посчитал косинусное расстояние между целевым фильмом и всеми остальными

```python
m_data = m_data.collectAsMap()
```
